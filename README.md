# rutracker-downloader

CLI-утилита, которая по поисковому запросу на RuTracker скачивает **только
`.torrent`-файлы**. Содержимое раздач не качается, торрент-клиент не
запускается, файлы никуда не добавляются.

Задача, под которую написано: собрать электронные книги Станислава Лема,
исключив аудиокниги и аудиоспектакли.

Что делает утилита:

* обходит **все** страницы выдачи, а не только первую;
* отсеивает аудио по названию и разделу форума, оставляя текстовые форматы
  (FB2, EPUB, PDF, DJVU, MOBI, AZW, DOC, TXT);
* скачивает `.torrent` идемпотентно — повторный запуск не тянет уже
  скачанное и ничего не перезаписывает;
* держит паузу между запросами и внятно сообщает, если сессия протухла.

## Установка

```bash
git clone https://github.com/megannnn98/rutracker-downloader
cd rutracker-downloader
uv sync
```

Нужен Python 3.13+; `uv` поставит интерпретатор и зависимости сам.

## Настройка

Форум закрыт Cloudflare-проверкой, которую обычный HTTP-клиент пройти не
может, поэтому сессия берётся из браузера. Два шага:

```bash
# 1. Откройте rutracker в Firefox, дождитесь прохождения проверки, затем:
uv run python scripts/export_firefox_cookies.py

# 2. Укажите User-Agent того же браузера (about:support -> «Строка агента пользователя»)
cp .env.example .env
$EDITOR .env      # RUTRACKER_USER_AGENT=...
```

`cf_clearance` живёт около 30 минут и привязан к паре IP + User-Agent, так что
экспортируйте cookies прямо перед запуском. Подробности и разбор, почему логин
с паролем не работает, — в [docs/authentication.md](docs/authentication.md).

## Запуск

```bash
uv run python -m rutracker_downloader --query "станислав лем"
```

Файлы лягут в `./output`. Другой каталог — через `--output`:

```bash
uv run python -m rutracker_downloader \
    --query "станислав лем" \
    --output ./torrents/stanislaw_lem
```

В конце печатается статистика:

```
страниц выдачи обработано : 4
найдено раздач           : 163
дубликатов пропущено     : 0
исключено как аудио      : 137
неопределённых пропущено : 0
без ссылки на .torrent   : 0
скачано новых            : 26
уже существовало         : 0
ошибок                   : 0
```

### Посмотреть без скачивания

`--dry-run` показывает, что было бы скачано, и не создаёт ни одного файла —
включая сам каталог вывода:

```bash
uv run python -m rutracker_downloader --query "станислав лем" --dry-run
```

Ещё есть `--verbose` для подробного лога. Полный список флагов, переменных
окружения и кодов возврата — в [docs/cli.md](docs/cli.md).
